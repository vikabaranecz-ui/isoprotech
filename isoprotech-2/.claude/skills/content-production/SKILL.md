## Role
Full execution engine for creating publish-ready content pieces: blog posts, articles, service pages, and guides.

**Triggers:** "write a post about", "draft an article", "create content for", "blog post over"  
**Not this skill:** Content strategy/planning → use `content-strategy`; Social captions only → use `social-content`

## First: Load Context
Read `marketing-context/SKILL.md` for brand voice, personas, and keyword context before writing anything.

## Three Operating Modes

### Mode 1 — Research & Brief
- Identify top 5–10 ranking pieces for the target keyword
- Map search intent (informational, commercial, navigational)
- Gather 3–5 credible, citable sources
- Produce a content brief: keyword, angle, H2 structure, internal links

### Mode 2 — Draft
- Outline first: 4–7 H2 sections
- Intro formula: **probleem → oplossing → geloofwaardigheid** (3–4 zinnen max)
- Each section: state point first, prove with example/stat, add takeaway
- Conclusion: samenvatting + volgende stap + CTA

### Mode 3 — Optimize & Polish
- SEO pass: title tag, H1, keyword placement, meta description
- Readability audit: target Flesch score 60+, sentences 15–20 words
- Structure validation: every H2 earns its place
- Internal links: 2–4 minimum with descriptive anchor text
- Pre-publish checklist (pass/fail gates)

## Intake Questions (Ask in One Shot)
1. Onderwerp / werktitel?
2. Doelzoekwoord (als SEO-relevant)?
3. Doelgroep en kennisniveau?
4. Doel: informeren, converteren, autoriteit opbouwen?
5. Gewenste lengte?
6. Bestaande content om naar te linken?

## Key Principles
- **Geen vage claims.** "Veel bedrijven..." = rode vlag. Citeer een specifiek getal of laat het weg.
- **Intro:** Begin met het probleem, dan wat dit artikel eraan doet. Geen "In de huidige digitale wereld..."
- **Leesbaarheid:** Max 4 zinnen per alinea. Actieve stem. Leg jargon uit.
- **Taal:** Nederlands (België). Schrijf in "u"-vorm.

## Proactive Flags
- 🚩 Thin content risk (concurrenten 2.000+ woorden, wij 400)
- 🚩 Keyword kannibalisatie (intern al een pagina voor hetzelfde zoekwoord)
- 🚩 Intent mismatch (artikel past niet bij zoekintentie)
- 🚩 Ongeciteerde claims
- 🚩 Geen zichtbare CTA terwijl doel "converteren" is

## Output Artifacts
1. Content brief met keyword, publiek, invalshoek, H2-structuur
2. Complete draft met H1, secties, conclusie, bronauteurs
3. SEO-geoptimaliseerde versie met title tag en meta description
4. Leesbaarheidsrapport
5. Pre-publicatie checklist
