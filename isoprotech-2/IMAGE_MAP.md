# Image Upload Guide

Upload all images to `public/images/` in your GitHub repo.
After upload, they will be served at `/images/filename.jpg`.

## Required files

### Logo
```
public/images/logo-white.png        ← White logo (for dark backgrounds)
public/images/logo-dark.png          ← Dark logo (for light backgrounds)
public/images/og-isoprotech.jpg      ← Open Graph image (1200×630px)
```

### Project photos
Upload to `public/images/projects/`:
```
gevelisolatie-crepi-meise.jpg        ← Gevelisolatie + crepi project Meise
gevelisolatie-crepi-antwerpen.jpg    ← Gevelisolatie + crepi Antwerpen
dak-gevelisolatie-mechelen.jpg       ← Dak + gevel Mechelen
gevelisolatie-crepi-antwerpen-2.jpg  ← Gevelisolatie Antwerpen (2e project)
gevelisolatie-ekeren.jpg             ← Gevelisolatie Ekeren
spuitkurk-mortsel.jpg                ← Spuitkurk project Mortsel
plat-dak-renovatie.jpg               ← Plat dak renovatie
dak-gevelisolatie-wilrijk.jpg        ← Dak + gevel Wilrijk
dak-gevelisolatie-schilde.jpg        ← Dak + gevel Schilde
crepi-schoten.jpg                    ← Crepi project Schoten
dakisolatie-antwerpen.jpg            ← Dakisolatie project
```

### Service-specific photos
Upload to `public/images/services/`:
```
asbestverwijdering.jpg               ← Asbestverwijdering foto (NIEUW NODIG)
dakkapellen.jpg                      ← Dakkapel foto (NIEUW NODIG)
```

## Recommended image specs
- Format: JPG or WebP
- Max width: 1400px
- Quality: 80-85%
- File size: under 200KB per image
- Aspect ratio: 16:9 or 4:3 for project photos
