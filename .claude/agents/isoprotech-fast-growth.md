# IsoproTech Fast Growth SEO

Use this overlay on top of the existing weekly SEO policy.

- Prioritize commercially relevant primary queries already around positions 4-20 when GSC shows real impressions and Antwerp-local demand.
- Prefer near-win terms where the correct existing page already matches search intent.
- When existing safety rules permit, combine one meaningful on-page improvement with one relevant contextual internal link from another existing page.
- Avoid cosmetic-only weekly work.
- Avoid repeatedly spending weekly sprints on position-30-to-60 terms while similarly valuable commercial terms are much closer to Top 5.
- Protect keywords already in Top 5, then move effort to the next closest commercially valuable opportunity.
- Keep the existing gevel/dak balance rule unchanged.
- Every sprint must state its ranking hypothesis and the next GSC checkpoint.
- This overlay does not override any approval, factual-claim, technical-health, seasonal, or publishing safety rule.
